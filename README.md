# আঠারবাড়ীয়া আইডিয়াল কিন্ডারগার্টেন — Vercel আপডেট নির্দেশনা

এই ফোল্ডারের ফাইলগুলো সাধারণ স্ট্যাটিক সাইট। কোনো বিল্ড কমান্ড লাগে না।
`firebase-config.js` ফাঁকা থাকলে অ্যাপ ফোন/কম্পিউটারের ব্রাউজারেই তথ্য রাখে (ক্লাউড ছাড়া)।

## আগে জেনে রাখুন
- আগের **একই Vercel প্রজেক্টেই** আপডেট করতে হবে। নতুন প্রজেক্ট খুললে লিংক বদলে যাবে এবং আগের লিংকে থাকা তথ্য নতুন লিংকে দেখা যাবে না।
- আপডেটের আগে সম্ভব হলে বর্তমান তথ্যের স্ক্রিনশট বা প্রিন্ট রেখে দিন।

## পদ্ধতি ক: GitHub দিয়ে ডিপ্লয় করা থাকলে
1. ZIP আনজিপ করুন।
2. GitHub-এ আপনার রিপোজিটরি খুলুন → **Add file → Upload files**।
3. আনজিপ করা ফোল্ডারের **ভেতরের সব ফাইল** (index.html, sw.js, manifest.json, আইকন, firebase-config.js, vercel.json ইত্যাদি) টেনে আনুন। ফোল্ডারটি নয়, ফাইলগুলো। একই নামের ফাইল বদলে যাবে।
4. **Commit changes** চাপুন।
5. Vercel নিজে থেকে নতুন ডিপ্লয় শুরু করবে। Vercel-এ প্রজেক্টের **Deployments** ট্যাবে "Ready" দেখা গেলে শেষ।

## পদ্ধতি খ: কম্পিউটার থেকে (Vercel CLI)
1. কম্পিউটারে Node.js ইনস্টল করুন।
2. আনজিপ করা ফোল্ডারে টার্মিনাল খুলুন।
3. `npx vercel --prod` চালান। প্রথমবার লগইন করতে বলবে।
4. "Link to existing project?" জিজ্ঞেস করলে **Yes** দিয়ে আগের প্রজেক্টটি বাছুন।

## আপডেটের পর
- ফোনে অ্যাপ বন্ধ করে আবার খুলুন, দরকার হলে পাতা একবার রিফ্রেশ করুন।
- নতুন ভার্সনে: নতুন লোগো, এন্ট্রি সম্পাদনা/মোছার অপশন।
